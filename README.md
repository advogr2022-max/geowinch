| `PCANBasic.dll` | CAN-обмен через PEAK (PCAN-USB / PCAN-Virtual) | из релиза |

### Как проверить отправку 0x101 (вариант A — с железом)

1. PCAN-USB подключён, драйвер PEAK установлен.
2. Запустить PCAN-View → канал `PCAN_USBBUS1`, скорость **250 kbit/s**.
3. Запустить программу, нажать и **удерживать «Сирена»**.
4. В PCAN-View видно `101` каждые ~500 мс: `57 43 <main> <mid> <rev> 00 00 00`. Контроллер отвечает `201` (`57 43 53 ...`).

### Как проверить отправку 0x101 (вариант B — без железа, виртуально)

1. Установить **PCAN-Virtual CAN Interface** (бесплатно, с сайта PEAK-System — тот же пакет, что и драйверы PCAN, версия с поддержкой Virtual).
2. В PCAN-View выбрать виртуальный канал **PCAN_VIRTUAL1** (номер 0x51 — тот же, что USBBUS1), скорость 250 kbit/s.
3. Запустить программу, удерживать «Сирена» — видно `101` каждые ~500 мс.

### Правки относительно v5.0.0 (суммарно)

1. `WCAnalysis.h` — таймер `ActSignalHorn_101_Time_old`.
2. `WCAnalysis.cpp` — `ActSignalHorn()`: кнопка «Сирена» шлёт CAN 0x101 (`W C + версия`) каждые 500 мс при удержании.
3. `WCAnalysis.cpp` — `ActCtlUnitCAN_O()`: снята блокировка `StatusLvl != Ready → return`.
4. `GUIMain.cpp` — `FormShow()`: надпись «ТЕСТОВАЯ ВЕРСИЯ» (чёрная, жирная) + кнопка «Выход» над «Ручное управление».
