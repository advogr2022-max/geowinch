# Geowinch

Проект Geowinch — ПО панели управления (HMI) геофизической лебёдки. Исходная база — WinchCtrl v5.0.0 (клон test5), сборка RAD Studio 12 (C++ Builder).

## Версия 0.0.1 — тестовая (проверка CAN-обмена панель ↔ контроллер)

### Цель версии

Проверить принципиальную возможность двустороннего обмена между панелью (HMI) и контроллером
Bosch Rexroth RC12-10/30 по CAN-шине. Все штатные проверки и блокировки обмена **отключены** —
панель должна гарантированно слать сигнал на шину.

### Что изменено относительно базы v5.0.0 (3 правки)

| # | Файл | Правка |
|---|------|--------|
| 1 | `source/WCAnalysis.h` | Добавлена переменная таймера `ActSignalHorn_101_Time_old` |
| 2 | `source/WCAnalysis.cpp` — `ActSignalHorn()` | **Кнопка «Сирена»**: при нажатии/удержании панель отправляет CAN-сообщение **0x101** (`W C + версия ПО`) **каждые 500 мс**. Отпустили — отправка прекращается |
| 3 | `source/WCAnalysis.cpp` — `ActCtlUnitCAN_O()` | Убрана блокировка отправки `CtlUnitCAN_StatusLvl != Ready → return` — панель шлёт CAN независимо от статуса готовности |

Больше ничего не менялось: вся остальная логика (тормоза, автоматы, приём статусов) — как в оригинале.

### Как проверить (инструкция)

1. **Запустите** `release/v0.0.1/WinchCtrl_TEST_v0.0.1.exe` на панели (PCAN-USB подключён к контроллеру, шина 250 кбит/с).
2. **Подключите CAN-анализатор** (PCAN-View / любой) к шине.
3. **Нажмите и удерживайте кнопку «Сирена»** на экране панели.
4. На анализаторе должно быть видно:
   - панель отправляет **0x101** каждые ~500 мс (`57 43 <main> <mid> <rev> 00 00 00` = `W C <версия>`);
   - контроллер отвечает **0x201** (`57 43 53 ...` = `W C S <версия>`).
5. Отпустите кнопку — поток 0x101 прекращается.

**Критерий успеха:** на шине видны и 0x101 (панель → контроллер), и 0x201 (контроллер → панель).
Это подтверждает двусторонний обмен; дальше можно настраивать штатный обмен данными.
